# rutbergphilip/homebrew-tap

Homebrew casks for apps by [rutbergphilip](https://github.com/rutbergphilip).

## NoteIt

```sh
brew install --cask rutbergphilip/tap/noteit
```

[NoteIt](https://github.com/rutbergphilip/noteit) is a native macOS notes app. The cask is updated automatically when a new release is published.
